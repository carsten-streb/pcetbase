PCETbase — open proton-coupled electron transfer (PCET) thermochemistry database: BDFE, E°, pKa, hydricity

Solution X–H and M–H bond dissociation free energies (BDFEs) and hydricities ΔG(H⁻) on a common scale.
Canonical value per entry: standard redox potential E°(V vs H₂) in the stated solvent; the table shows stored values, and the verification panel recomputes each one live from its legs as a consistency check.
Entries with flags (⚑, hover for details) carry caveats from the source.
Coverage grows by release; see the CHANGELOG.

Pair — HAT feasibility

Convention: for abstraction Cat• + H–Sub → Cat–H + Sub•, ΔG°(HAT) = BDFE(Sub–H) − BDFE(Cat–H); negative = downhill. Values are the recommended (★) measurement of each couple. ΔG° of H-atom transfer only — says nothing about kinetics or mechanism (ET-PT vs HAT).

How the data were curated
PCETbase entries are extracted from the published literature (critical reviews and primary papers), working from the papers’ tables, text and supporting information. Each entry stores the primary measurables (potentials with their reference electrode, pKa values); BDFEs are recomputed from these with one consistent constant set rather than copied. Every stored value passes automatic thermochemical closure checks (Bordwell equation, H-atom potential, hydricity cycle where applicable) and a structural validation suite; the same checks gate every change through continuous integration, so a value that does not close thermochemically cannot enter the database. Each entry carries a public verification record — source, extraction route, whether the primary literature was page-verified, checks run — shown in its Curation trail and downloadable as the full verification ledger. All changes enter through reviewed pull requests on GitHub, and every addition and release is reviewed and approved by a human curator (C. Streb). Values that could not be fully verified carry explicit flags rather than silent corrections.
