Pair — HAT feasibility

Convention: for abstraction Cat• + H–Sub → Cat–H + Sub•, ΔG°(HAT) = BDFE(Sub–H) − BDFE(Cat–H); negative = downhill. Values are the recommended (★) measurement of each couple. ΔG° of H-atom transfer only — says nothing about kinetics or mechanism (ET-PT vs HAT).

Data & constants. Values (E°(V vs H₂), BDFE, pKa, component potentials) from Agarwal, Coste, Groff, Heuer, Noh, Parada, Wise, Nichols, Warren, Mayer, Chem. Rev. 2022, 122, 1–49, doi:10.1021/acs.chemrev.1c00521; for review-derived entries the Source column links the review DOI, and [ref N] gives the original citation reference number within that review. External entries link their own primary DOI. See also the correction to the 2010 review, doi:10.1021/acs.chemrev.1c00791. Flags: hess = value in source derived by Hess's law; limit = inequality bound; approx = approximate; lowprec = low-precision printed value; dmso-unc = larger uncertainty in DMSO constants; lowT = measured at −80 °C; excited = excited-state potential; check-src = internal inconsistency in source, under review; recomputed = BDFE recalculated here from the primary E°/pKa with corrected constants; avg = average over n sequential H-atom transfers. ★ marks the recommended value where several independent measurements of the same couple/solvent exist; all values are kept with their sources. External entries (Src = DOI) are extracted from the primary literature; POM-cluster data include work of the Matson group (polyoxovanadate-alkoxides). BDFEs of pairs are effective BDFEs (BDFEeff). Always consult the primary source before quantitative use.
